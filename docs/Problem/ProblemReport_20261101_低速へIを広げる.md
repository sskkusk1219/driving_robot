# 20261101 C10 の偏差の積分 I を 7.5 km/h 未満と惰行の補助へ広げる（境目で 0 に戻す段差をなくす）

**状態: クローズ（2026-11-02）**

I（偏差の積分）は 7.5 km/h 以上の行だけで働き、減速で 7.5 km/h を切る瞬間に 0 へ戻る。このとき I が足していたブレーキ 0.1〜0.4% が急に抜ける。案A（境目で 0 にせず保つ）と案B（7.5 km/h 未満でも貯める）を実機で比べる。あわせて、今は I を使っていない惰行の補助に I を入れる案C も試す。根拠は 6 モード `drive_log_real_20261101_114437`〜`133015`。

**結論: 案A・B・C とも不採用（Claude 判断 2026-11-02）。**（**案A・B は再検討予定**: 不採用は FF の表の段差と重なっていたため、ProblemReport_20261102_表の境目の段差 で段差を直した後に、そのレポートの段6b〜6d で走り直す。案C は再検討しない） 実機 12 本（`20261101_213345`〜`20261102_015737`）で、境目の段差は案A・B で消えた（U 最大 0.27→0.008%）が、7.5 km/h 未満の |偏差|>0.5 は off 2.85 s（同じ設定の 11-01 は 4.00 s）に対し A・B とも 3.60 s で良くならなかった。案C は惰行の行の |偏差|>0.2 が詰まらなかった。本体 yaml は `c10_integral_low_speed: "off"`・`c10_integral_coast_assist: false` のまま（コードは既定 off で残す）。

## 問題

用語: **偏差** ＝ 実車速 − 基準車速（＋は速すぎ。ログ `deviation_kmh`）。I の中の dev は逆向き（基準 − 実車速）。**I** ＝ C10 の上乗せに足す偏差の積分（`tests/research/c10_integral.py`。a_I ＝ 貯めた量 ÷（τ × Ti）、Ti ＝ 4τ。ブレーキの τ 0.9 s・アクセル 1.1 s）。**停C** ＝ 停止の手前のブレーキの行で、P の τ を「止まるまでの残り時間」に縮める仕組み（`stop_end_p_enabled`）。**境目** ＝ meta `stop_max_speed_kmh`（7.5 km/h）。

- I は ProblemReport_20261031_効き始めの近くのブレーキ で本体 on にした。6 モードで \|偏差\|>0.5 の合計 20.95 → 13.50 s
- 13.50 s のうち 5.30 s は 7.5 km/h 未満で、ここでは I が働いていない
- 境目で I を 0 に戻すことが、それ自体で指令の段差になっている
