# 20261031 発進でブレーキを離すのが早い

**状態: クローズ（2026-11-01）**

強い発進でブレーキが基準の動き出しより約 0.4 秒早く min へ戻り、車がクリープで先に動いていました（+0.55〜+0.74 km/h）。原因は踏み替えのすき間が実際より長いことでした。
案 A（`launch_gap_tight`: 発進のすき間を 1 行詰める）と案 B（`launch_brake_band`: 弱い発進はアクセルを使わずブレーキの帯で動かす）を両方採用し、本体 yaml を on にしました（`0fe9b57`）。
5 モード（`032308` W・`035535` U・`042004` H・`043415` US06・`044703` AMA）で、強い発進の最大は U 平均 +0.60 → +0.48・US06 135 s +0.70 → +0.59・AMA 平均 −0.14、最大逸脱は 5 モードとも悪化なし（U 0.85 → 0.54）。
残り: 帯の間の約 −0.2 km/h の遅れ（U 346 s の最小 −0.08 → −0.26〜−0.29）、ゆっくり動いてから急に上がる発進（US06 500 s・AMA 840 s）。

## 問題

- 基準がまだ 0 km/h の間に、ブレーキが約 9.3% から min の 4.2% へ 1 行で離れ、車はクリープ（両ペダル min で進む動き）で動き出します
- 基準が動き出す行で、車はすでに 0.7 km/h 出ています。UDDS の強い発進 6 か所で +0.55〜+0.65 km/h、毎回同じ形です
- 発進は人が見て一番分かりやすい所で、車は基準より先に動き、その後ぐっと加速します

用語:

| 用語 | 意味 | 今の値（pkl `fwd_model_20261028_220204_hpi2_hold.pkl`） |
|---|---|---|
| min | ペダルの待機位置 | 4.2% |
| 効き始め | 踏み込むときに効き始める開度 | ブレーキ 6.15%（min＋1.95） |
| 動き出す開度 bk | ブレーキを離していって、止まっている車が動き出す開度 | 8.9%（min＋4.705） |
| 保持の開度 | 低速の一定車速を保てるブレーキ開度（手順2 の測定） | 7.61%（2.04 km/h）〜 7.01%（4.67 km/h） |
| すき間 | 踏み替えで「両ペダルの指令が min」の行数（1 行 0.05 s） | 発進は 5 行 |

## 検討した案

| 案 | 内容 | 判断 |
|---|---|---|
| **A. 発進のすき間を実測に合わせる** | 停車からの発進のブレーキ → アクセルだけ、すき間を「戻る時間 − 余裕 1 周期 − アクセルが動くまでの 1 行」にする（5 → 3 行）。アクセルの時刻は変えない。**ブレーキだけ 0.1 s 遅れる** | **採用（第 1 段）**。原因に直接効き、変更が小さい。見込み 最大 +0.6 → +0.35〜+0.4（推測: 0.1 s × 2.3 km/h/s） |
