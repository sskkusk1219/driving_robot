# 20261103 低速のブレーキで、効いている開度を保つ（案③）

**状態: クローズ（2026-11-03）**

結論: 案③ は不採用（実機 `081809`〜`102416` で 3 モードとも遅すぎで悪化。コードは既定 off で残す）。速すぎの原因は「停車前に基準が 0.5 km/h 未満で這う所で FF が止まった開度より浅く戻す」ことと分かり、ProblemReport_20261103_停車前の這う基準 へ引き継いだ。

7.5 km/h 未満の速すぎ（+0.5 超）は、計画の FF が停車の手前で 0.2 秒に 1〜2% ブレーキを戻し、クリープが勝って車が加速し直すことで起きる。FB が戻したのではない。直前に効いていた開度を起点にして、基準の加速度が変わった分だけ動かす（案③）を試す。根拠は 11-02 夜の WLTP `drive_log_real_20261102_202444`・UDDS `205725`・US06 `212141`、pkl `fwd_model_20261028_220204_hpi2_hold_stop_w_lw.pkl`。

## 問題

用語: **FF** ＝ 計画が前もって決めた開度。**FB（C10）** ＝ 偏差を見て足し引きする量（ログではマイナスがブレーキを深く）。**偏差** ＝ 実車速 − 基準（＋が速すぎ）。**加速度 0 の開度** ＝ アクセルを離して、加速も減速もしないブレーキの開度。

- ProblemReport_20261102_表の境目の段差 の残る課題: 低速の偏差（W 385・444 s、U 727・766 s、US06 8 s）
- 7.5 km/h 未満に I を足す案は 2 回不採用（U 956・1186 s が遅すぎ）

## 検討した案

| 案 | 内容 | 判断 |
|---|---|---|
| ① 停車ごとに偏りを少しずつ覚える | 走行中に遅い学習で次の停車へ持ち越す | 不採用。1 回の停車の中に速すぎ・遅すぎが両方あり（W で最大 +0.18〜+0.86・最小 −0.06〜−0.37）、7.5→0 km/h の平均偏差は ±0.2 で向きもまちまち。1 本目の最初の停車に効かない |
| ② 7.5 km/h 以上の I を低速の FF に引き継ぐ | I そのものは持ち込まない | 不採用。大きさ・向きが合わない（上の事実） |
| ③' 停C・保持の PI を強くする | 場面ごとの FB を強化 | 不採用。停C・C10 は遅れに負ける・強くすると往復。保持の PI は約 16 倍のゲインが要る |
| D1〜D3 加速度 0 の開度を下限にする | 下限 u0(v) を FF にかける（D3 は停車ごとに u0 を直す） | 保留。u0 のデータが約 1% 食い違い、0.1% の誤差が 0.7 km/h/s になる。D3 は ③ が駄目なときの次の手 |
| DOB を低速でも使う・速くする | 薄めない／時定数を短く | 不採用。測っているのは戻す前のずれ・ずれが出てから動くのは P と同じ |
| **③ 効いている開度を保つ（採用）** | 低速のブレーキで、範囲に入った時の実開度を起点にし、基準の加速度の変化 ÷ c だけ動かす。表の答えを使わない | 採用（ユーザー決定）。ユーザーの読み「384.75 s の 8.69% は合っている。以降の加速度が変わらないので保つか踏み増す」 |
