## 2. 現在ステータス（#4）の設計

### サーバー

- `src/infra/log_buffer.py`（新規）: `logging.Handler` のサブクラス。直近 500 行をリングバッファ（`collections.deque`）に持つ。1 行 = `seq`（連番）・`t`（アプリ起動からの経過秒）・`time`（ISO 時刻）・`level`・`logger`・`message`。スレッドセーフ（`threading.Lock`）。
- アプリ起動時（`src/web/app.py` の lifespan）に `logging.getLogger("src")` に付け、そのロガーのレベルを INFO にする。`app.state.log_buffer` に置く。
- API `GET /api/v1/drive/log?after=<seq>`: `seq > after` の行を古い順に最大 200 行返す。`{"lines": [...], "last_seq": n}`。`after` 省略時は直近 200 行。
- **ログの中身を足す**（今は INFO が少なく流しても何も出ないため）。tests/research の出し方に倣い、日本語で 1 行ずつ:
  - ロボットの状態遷移（`RobotController._transition`）: `状態: STANDBY → INITIALIZING`
  - 初期化の各ステップの開始・結果（`[OK  ]`・`[NG  ]` と詳細）
  - 走行前チェックの各項目の結果
  - 学習サイクル（`src/app/learning_cycle.py`）: 段階が変わるたび（段階名・何本目/何本中）、各走行の開始・終了、学習の結果（コストなど progress に出している値）、エラー・中断
  - 走行の開始・終了（自動運転・学習運転とも）
  - 既存の `_logger` の呼び出しはそのまま。制御ループの周期処理（10ms ごと）にはログを足さない（行が溢れるため）。

### 画面

- `DriveMonitorScreen` に現在ステータスの部品を足す（学習運転で使う。自動運転でも使えるように prop で on/off）。
- ターミナル風: 等幅フォント、`[  12.3s] メッセージ`、WARNING は黄・ERROR は赤、新しい行が来たら一番下へ自動スクロール（ユーザーが上へスクロールしているときは止める）。
- 1 秒ごとに `GET /api/v1/drive/log?after=<最後の seq>` を取りに行く（画面を開いている間だけ）。
- 行が無いとき・開始前は、いまの状態から一言を出す（STANDBY: 初期化を実行してください／READY: 「開始」を押せます／それ以外: 状態名）。
- 学習サイクルの段階表示（今の `resultPanel` の段階名・何回目・最良コスト）は残し、ログの上に 1 行で出す。
- 枠が小さい（最下段は高さ 0.25）ので、学習運転では最下段を高くする（例: 車速 1 : ペダル 1 : 進み 0.25 : 最下段 0.6）。
