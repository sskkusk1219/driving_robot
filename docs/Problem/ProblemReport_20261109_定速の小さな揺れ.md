# 20261109 定速の小さな揺れ（偏差の ± の行き来）を P の帯と D で抑え、IWR で測る

**状態: 進行中（⏸ PDCA-8 の計画のユーザー確認待ち。ユーザー決定 11-11: 本体を PDCA-6〔16 dB〕にする・PDCA-6 を最良として制御側の手を優先度順に PDCA で回す）**

定速・ゆるい坂で、偏差が ±0.05〜0.09 km/h を約 0.8 Hz で行き来し、アクセルも同じ周期で往復する。原因は C10 の P が
見込む効き（表の傾き）より実際の効きが 3〜4 倍強く、ループが設計の 3〜4 倍の速さで回って安定の限界の近くで揺れること。
小さい偏差だけ P を弱める（案1 の変形）と D（位相を進める）を順に試し、IWR（SAE J2951）を KPI に入れて判定する。
**実装は別レポートが終わってから始める（ユーザー指示 2026-11-09）。**

## 問題

- WLTP 1160〜1270 s・1690〜1720 s など定速で、アクセルを踏んだり緩めたりして偏差 0 を境に + と − を行き来する（ユーザー報告）。
- 偏差は小さく（p95 0.08〜0.09 km/h）、今の KPI（符号反転のしきい値 0.3 km/h）には数えられない。しかしペダルの往復は
  定速の区間で 1.3〜1.5 回/s と、往復 KPI（全体 ≤0.4 回/s）の 3 倍以上。運転の質の指標 IWR も大きくなり、US06 は法規の目安
  ±2 % を超えている。

## 議論で確認した事実

用語:
- **偏差** ＝ 実車速 − 基準（CSV の deviation_kmh。正 ＝ 速すぎ）。C10 の内部では 基準 − 実車速（遅れていれば正）
- **P の強さ** ＝ 偏差 1 km/h あたり何 % 足すか。C10 は「偏差を τ ＝ deviation_c（6）× 遅れ L で 0 に戻す加速度」を表の傾きで開度に直す
- **局所の効き** ＝ 開度を少し動かしたときに出る加速度 [km/h/s/%]
- **IWR**（Inertial Work Rating、SAE J2951）＝ 加速側の慣性仕事（加速度 > 0 の行の 加速度 × 進んだ距離 の合計）が基準より何 % 多いか。
  ＋はバタバタ運転、−はなまし運転。ここでは 10 Hz・フィルタなし・中心差分で計算

## 検討した案

| 案 | 内容 | 判断 |
|---|---|---|
| 案1 そのまま | 偏差 ±0.0X 以内で開度を固定 | 不採用。開度全体を固定するとゆるい坂の基準に追いつかない。P だけでも硬い不感帯は、帯を出た瞬間に強い P が蹴り帯の幅で往復する（以前の「調停の保持 → 矩形発振」と同じ） |
| **案1 の変形（採用）** | 小さい偏差だけ P をなめらかに弱める（帯の中は r 倍、外は今と同じ傾きで値が連続） | 採用。大きい偏差の取り返しはほぼ今と同じなので、local_gain_brake（10-28 不採用、P 全体が弱まり取り返しが遅れた）の負け方を避けられる |
| **案2（採用）** | IWR を KPI に入れる | 採用。現象をそのまま数字にでき、車に依存しない標準の指標。車速信号のノイズでも上がり、± が打ち消すので、往復の KPI と区間別の内訳を並べて見る |
| 案3a DOB を速くする | Tq を短くする | 不採用。同じ遅れを抱えた強い加速度の FB になり、かえって揺れやすい |
| **案3b D を足す（採用）** | P の偏差を 遅れ L 先へ延ばす（要る加速度 − 実測の加速度） | 採用。位相を進めて揺れを減衰させる。案1 の後に足して比べる |

## ユーザー決定（2026-11-09）

- IWR の目標は **WLTP と UDDS で −0.2〜+0.4 %**（法規 ±2 % より厳しい）。US06 は記録だけ
- 符号が 0 をまたぐこと自体は許容する。**IWR と往復回数が目標に入れば良い**
- 案1 の変形を先に実施し、その上に D を足す。比べ方は **off → 案1 → 案1＋D**
- 案1: **r ＝ 0.5・e ＝ 0.1 km/h**（実機で 0.2 と比べる）
- D: **Td ＝ 遅れ L（ペダル別）・実測の加速度の窓 0.3 s**
- 掛ける範囲は **7.5 km/h 以上の C10 の行**（低速は対象外）
- D は帯の中でも弱めず全部の強さで足す（Claude 提案、ユーザー了承）
- **実装は進行中の別レポートが終わってから始める**

## ユーザー決定（2026-11-10、段5 の後の議論）

- 次の手は **A: 効きの見積もりを直す**。P を「表の傾き」ではなく、手順2 で測った**局所の効きの倍率**で割って弱める。
  **I と DOB は今のまま**（＝「P を割ると同時に I を速くする（P ÷ Ti を保つ）」と同じ）。**D を足すかは P・I の後に判断する段を計画に入れる**（段12b・12c）
- 弱め方は **B1（倍率で全部割る ＝ 実際の τ を 6 × L）と B2（実際の τ を 3 × L ＝ 今の約 1/2。限界感度法の 0.45 Ku 相当の推定）の両方を試す**
- 掛ける範囲: まず **定速だけ**（要る加速度 ＜ 0.3 km/h/s のアクセルの行）で B1・B2 を比べ、勝った方で **加速中も**（7.5 km/h 以上のアクセルの行すべて）を試す（案 Y）
- 手順2 は**局所の効きを測るためだけ**に走り直す（できる pkl は使わない。表は今の pkl のまま）。**定速の保持 5 → 10 秒**（手順2 の段は増やさない）
- 勝ち負けの順番: **最大偏差 ＞ p95 ＞ IWR とペダル往復**。IWR・往復が良くなっても偏差が大きくなる案は負け。
  最大偏差は**案が掛かる場面（7.5 km/h 以上）で off より悪くならないこと**。全体の最大と目標（WLTP・UDDS 0.5、US06 1.0 km/h）との差も毎回報告。
  7.5 km/h 未満の停車の手前の最大（U 728 s +0.82 など）はこの問題では直さない
- チャットで受け取った意見を `docs/ideas/PID制御と調整方法.md` に保存。取り入れるのは「倍率で振る（B1・B2）」と「D は測定値の微分＋短いフィルタ（作り直すとき）」
