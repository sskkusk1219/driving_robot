# ユーザー用のメモ CLAUDEは読込みも書き込みもしなくて良い

全ての条件を、判定する順に書きます。

## 使う言葉

| 言葉 | 意味 |
|---|---|
| 基準車速 v | いまの基準車速 |
| 要る加速度 | 基準から計算した、いま出したい加速度 |
| ペダルを離した加速度 | 両ペダルを離したときの車の加速度。クリープ車速未満ではプラス（クリープで加速する） |
| 低速 | v が 7.5 km/h 未満。7.5 は停止側の表があるデータの上限（pkl の `stop_max_speed_kmh`） |
| 発進の途中 | 停車保持を抜けてから、計画で初めてアクセルを踏む直前まで（段5-2 で作った判定）。UDDS 1251〜1256 秒の「0 → 1.6 km/h で保つ」も含む |
| 戻し | 直近 3 秒に計画した中で一番深いブレーキより、いまの開度が浅いこと |
| 踏み込み・保持 | 戻しでないこと |

## 判定 1: 停車保持かどうか（今と同じ）

- 基準がいま 0 で、かつ 0.5 秒後も 0 なら、停車保持のブレーキ（17.9%）にする。
- 停車保持なら、ここで終わり。
- 外す 0.5 秒は「停止側の表を引くのは停車 0.5 秒前だけ」のほう。こちらは停車保持の判定なので残す。

## 判定 2: アクセル・惰行・ブレーキのどれにするか

「要る加速度」と「ペダルを離した加速度」を比べる（帯は 0.25 km/h/s）。

| 条件 | 決めるもの |
|---|---|
| 要る加速度 ≥ ペダルを離した加速度 ＋ 0.25 | アクセル |
| 要る加速度 ≤ ペダルを離した加速度 − 0.25 | ブレーキ |
| その間 | 惰行（両ペダルを離す） |

「ペダルを離した加速度」は、車速で取り出す表を変える。

| 車速 | 取り出す表 | 値の例 |
|---|---|---|
| 7.5 km/h 以上 | 本体（今と同じ） | ― |
| 低速 | 停止側の表（クリープを知っている） | 1.6 km/h で +1.31 km/h/s、約 4 km/h で 0 |

これで「クリープ車速未満で、要る加速度がクリープの加速度以下ならブレーキで調整」になる。

- 例: 1.6 km/h で一定（要る加速度 0）なら、0 ≤ 1.31 − 0.25 なのでブレーキ。
- 今は本体の −0.22 km/h/s と比べているので、ここが惰行（ブレーキを離す）になっている。

## 判定 3: ブレーキのとき、どの表を引くか

| | 車速 | 場面 | 引く表 | 今との違い |
|---|---|---|---|---|
| B1 | 7.5 km/h 以上 | 踏み込み・保持 | 本体（踏み込みの効き） | 同じ |
| B2 | 7.5 km/h 以上 | 戻し | 本体（戻しの効き） | 同じ |
| B3 | 低速 | 発進の途中 | 発進側の表 | 今は「基準が上がっている間」だけ。基準が一定（1.6 km/h で保つ）だと本体になっていた |
| B4 | 低速 | 発進の途中でない・踏み込み・保持 | 停止側の表 | 今は「停車 0.5 秒前」だけ。それ以外は本体 |
| B5 | 低速 | 発進の途中でない・戻し | 本体（戻しの効き） | 今もほぼこれ（偶然そうなっていた）。条件で決める |

- B4 と B5 の分け方（踏み込みか戻しか）は、B1 と B2 とまったく同じ判定。手順は次のとおり。
  1. まず停止側の表で開度を解く。
  2. その開度が、直近 3 秒に計画した一番深いブレーキより浅ければ、本体の戻しの効きで解き直す。
- B3 では、5-2 で入れた例外（動き出す開度より深い行は停止側の表へ）を外す。発進の途中は全部発進側の表。

## 判定 4: アクセルのとき、どの表を引くか（今と同じ）

| | 車速 | 引く表 |
|---|---|---|
| A1 | 7.5 km/h 以上 | 本体（アクセルの戻しの効きは段4-4 で外したまま） |
| A2 | 低速 | 発進側の表（5-3 で実測に替えた表） |

## 場面ごとに当てはめると

| 場面 | 判定 | 表 |
|---|---|---|
| 減速して停車へ（ブレーキを踏み込む） | B4 | 停止側 |
| 5 km/h で減速を緩める | B5 | 本体の戻しの効き |
| 停車保持から 0 → 1.6 km/h で保つ（UDDS 1252〜1256 s） | B3 | 発進側（17.9% から戻して約 9.0% で保つ） |
| 発進してアクセルで加速 | A2 | 発進側 |
| 減速して 1.6 km/h で保つ | 判定 2 でブレーキ → 戻しなら B5、踏み込み・保持なら B4 | 本体の戻しの効き／停止側 |
| 7.5 km/h 以上 | B1・B2・A1 | 本体（今と同じ） |
