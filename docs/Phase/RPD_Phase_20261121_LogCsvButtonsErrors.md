# 走行ログ CSV にボタン・エラーの列を足す（RPD_Phase_20261121_LogCsvButtonsErrors）

作成日: 2026-11-21 / 対象: `driving_robot`（src 本番のみ。tests/research は変えない）

**状態: 実装・確認済み（2026-11-21）** — 本番 DB の 3 走行で CSV を作って確認（§5）

## 1. なぜ作るか

ユーザーがログ画面から CSV をダウンロードして Excel で見る。走行ログの行には
[時間・基準車速・実車速・偏差・FF 指示・FB 指示・実開度%・実ストローク mm・電流 mA・エラー・スタート・P・N・D]
が要るが、今の CSV には次が無い。

| 項目 | 今 |
|---|---|
| スタート・P・N・D | 行に無い（`drive_session_messages` の level `BUTTON` の行にだけある） |
| エラー | 行にあるのはアクチュエータのアラームだけ。ソフトのエラー・警告は `error_events` にだけある |
| Excel | BOM なしの UTF-8 → 日本語（エラーの見出し）が文字化けする |

## 2. 決定事項（2026-11-21 の議論）

| # | 項目 | 決定 |
|---|---|---|
| 1 | FB 指示 | 分けない（`c10_effort_pct` の 1 列のまま） |
| 2 | ボタン | `btn_start`・`btn_P`・`btn_N`・`btn_D` の 4 列。押している間（押し始め〜押し始め＋秒数）の行は 1、他は 0 |
| 3 | エラー | `error_level`・`error_title` の 2 列。`error_events.first_at` の 1 行だけに入れる。対象は `session_id` がその走行のものだけ |
| 4 | 範囲の外 | ログの行が無い時刻（最初の行より前・最後の行より後）のボタン・エラーは、その時刻に行を 1 本足す（ボタン・エラー・timestamp 以外は空欄） |
| 5 | 列の数 | 分けない（全列＋新しい 6 列） |
| 6 | Excel | 先頭に BOM（`﻿`）。列の見出しは英語のまま |
| ― | 範囲 | 変えるのは src の CSV ダウンロードだけ。ランナー・DB スキーマ・`src/robot/core`・tests/research は変えない |

## 3. 重ね方の規則

- 新しい列は `csv_header` の最後（core の列と detail の旧列の後ろ）に `btn_start, btn_P, btn_N, btn_D, error_level, error_title` の順で足す
- ボタン: `parse_button_presses`（既存）で押下を読む。行の timestamp `t` が `[押し始め, 押し始め + seconds)` に入れば 1
  - 押し始めがログの最初の行より前、または最後の行より後なら、押し始めの時刻に行を足す（その行は 1）
- エラー: `first_at` 以上で最初の行に入れる。`first_at` が最初の行より前、または最後の行より後なら、`first_at` の時刻に行を足す
  - 同じ行に複数あれば `error_level` は重い方（ERROR > WARNING）、`error_title` は ` / ` でつなぐ
- 足した行は時刻順に元の行の間へ入れる（ストリームのまま。ボタン・エラーは数件なので先に読んでおく）
- ログの行が 1 本も無いセッションは、ボタン・エラーの行だけを出す

## 5. 確認の結果（2026-11-21）

ruff check 通過・`tests/unit/test_drive_csv.py`・`test_web_sessions_bad_id.py` 26 件成功。本番 DB の走行で `logs.csv` を作った結果:

| 走行（JST） | 行数（うち足した行） | ボタン | エラー |
|---|---|---|---|
| `b62ea143` 11-21 06:29 停止 | 557（2） | スタート・D は行に 1。記録の後の N（06:30:07）・スタート（06:30:10）は行を足した | なし |
| `10d64a8c` 11-20 21:26 非常停止 | 654（3） | 同上（N 21:27:14・スタート 21:27:18 を足した） | 21:26:55 の「非常停止（画面の非常停止ボタン）」をログの後に行を足して ERROR で出た |
| `95e310ce` 11-21 06:30 完了 | 247（0） | スタート 10 秒の間の 200 行が 1 | なし |

3 本とも先頭に BOM・行は時刻順。

残る制限: ログの範囲の中で、押している間に行が 1 本も無い押下（行の間の空きより短い押下）は CSV に出ない。押下は 1 秒以上・行は 0.05〜0.1 秒ごとなので、今の走行では起きない。
