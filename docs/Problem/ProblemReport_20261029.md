**状態: クローズ（2026-10-29）**

## 問題

- これまでの手順2（`215040` など）と手順3（段9 `053023`〜`065116` など）は、車速の跳びが入った状態で測っていた。ロボットは車速の差から加速度を見るので、約 1.3 秒ごとに加速度が 0 に見えるとげが入っていた（表の元データにも、DOB・局所の効きの当てはめにも）
