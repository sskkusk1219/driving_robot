# 人間の運転が再現できているか確認する

## 人間の運転を言葉で表現すると(手順3まで)
以下が、現在の制御に組み込まれているか議論して、必要な部分は取り入れたい
1. t,t+h,t+h2,t+h3,t+h4,,,基準車速を線形で見る(どこまで見るかは人それぞれ)
2. 現在の車速を見る(V0)
3. 次に合わせるべき車速を予測する\
    Xs先の車速に合わせるためには、どれくらいの加速度が必要そうと予測する
4. 予測した車速・加速度からクリープ/惰行車速で走れるか予測する\
    不可能ならペダル開度を予測する
5. ペダル操作

V0は現在位置を把握するためにも必要かと考えます。これは人間の運転にも則した考えで、いまどれだけの車速が出ていて、Xs先の車速に合わせるためには、\
どれくらいの加速度が必要そうだから、アクセル/ブレーキはこれくらいにしよう。と考えながら運転する

### 考え方として
- 発進
    徐々にブレーキを離していって、クリープ車速を出す
- 加速
    クリープ車速で走れるところはクリープで走り、足りない部分はペダル操作で加速する
    なるべく開度は一定に保つ
- 定常
    なるべく開度は一定に保つ
- 減速
    アクセルを緩めて減速するシーンはアクセルを緩めていく
    ペダル操作なしで惰行で減速できるところはなるべくペダル操作なしで減速
    ブレーキ減速が必要なシーンはブレーキで調整して、バタバタペダル操作しない
    なるべく開度は一定に保つ
- 停止
    一度踏んだら戻したりバタバタしないで、徐々に踏み増して減速して停止させる
- 全体として
    バタバタペダル操作するような運転しない
    なるべく開度は一定に保つ
    操作しないで追従運転できるところは、開度の変更はしない(偏差が±0.0X以内ならなど)
