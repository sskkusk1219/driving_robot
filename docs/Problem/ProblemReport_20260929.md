# 20260929 h1の決め方問題

**状態: 進行中（議論段階・段0 完了。再開は ProblemReport_20260921 段3 の後）**

ペダル選択（アクセル／惰行／ブレーキ）に使う先読み h1=1.0s には、データ由来の根拠が無い。
ProblemReport_20260921 の段2c として議論し、「反応時間（遅れ）の実測」までは進めたが、本レポートに分離した
（ユーザー判断 2026-09-29: 20260921 では h1 の深掘りを止めて段3 へ進む。ペダル選択の先読みが車ごとに違う課題は残るので別途扱う）。
現状は実測値（下の表）と暫定方針だけ。実装・実機比較は未着手。

## 問題

- h1（ペダル選択・レジーム判定に使う先読み）は 1.0s 固定。本番 `src/domain/model_training.py:103` の既定値を引き継いだだけで、
  データ由来の根拠が無い（`docs/memo.md` 1189 行に「根拠未決」の記録あり）。
- ペダル選択に効くので、車の応答（ペダルを踏んでから加速度が変わるまでの遅れ）が違えば最適な h1 も違うはず。
  合わないと、切り替えが遅れる（h1 が長すぎる）か、小さなずれに過敏になってペダルがばたつく（h1 が短すぎる）。

## 議論で確認した事実

用語: **遅れ** ＝ 指令（開度を切り替えた瞬間）から、加速度の変化が 63% まで進むまでの時間。

| 項目 | 内容 |
|---|---|
| h1 の定義 | 要求加速度 =（h1 秒先の基準 − 今の実車速）÷ h1 を、惰行加速度の ±`coast_band_kmhs`（0.5 km/h/s）と比べてペダルを選ぶ（`ff_candidate.py:416-438`） |
| h1 の仕事は 2 つ | **A. どのペダルを踏むか決める**（h1 だけで決まる。モデルの係数は使わない）／**B. 開度モデルの特徴量の 1 本**（アクセル `[0.5,1.0,2.6]`・ブレーキ `[0.1,0.2,0.7,1.0,2.3]`。`test_vehicle_20260929_051025.pkl`）。B は他のホライズンと並ぶので h1 単独の影響は薄い（係数が小さければなおさら）。**薄まるのは B だけで、A は薄まらない**（ユーザー指摘への回答） |
| h1 の使い道（5 か所） | ①ペダル選択 ②ブレーキ開度計算（`ff_candidate.py:553`）③特徴量 `dv1_x_v0` ④ホライズン探索の開始点 ⑤WLTP 格子（`wltp_grid.py:103`） |
| 格子の加速度軸 | config の h1 ではなく `DEFAULT_FEATURE_SPEC`（h1=1.0 固定）で計算（`wltp_grid.py` の `wltp_cell_stats`）。h1 を変えて格子も作り直すなら、格子の前に決める必要がある |
| CV-MAE では A を決められない | ペダル選択は学習データの上で点数にできない（実質Kp と同種。ProblemReport_20260921 6-10） |
| G 校正では遅れを測れない | `drive_log_real_20260928_155259.csv`（読み取り専用の試算）。加速は G を見ながら 20s かけて 0→70% の連続ランプ（開度変化と加速度変化の相関 0.49、遅れ 0〜0.3s で差が出ない。G で開度を動かす閉ループなので因果が混ざる）。ブレーキは 1s ごと 0.5% 刻み（相関 0.14） |
| 格子ステップ（HOLD_STEP）なら測れる | 同 155259。アクセルだけ切替 41 回: 遅れの中央値 **0.5s**（四分位 0.40〜0.55s。うち指令→実開度 50% が 0.45s＝アクチュエータの移動が大半）。アクセルを戻しながらブレーキを踏む同時切替 27 回: **0.25〜0.3s**。ブレーキ単独の切替は 0 回で、ブレーキだけの遅れは分離できていない。データ 1 本・試算スクリプトのみ（未検証） |
| 式の分解 | （h1 先の基準 − 実車速）÷ h1 ＝ **①先読み**（h1 先の基準 − 今の基準）÷ h1 ＋ **②ずれへの反応**（今の基準 − 実車速）÷ h1。h1 を短くすると②が強まる（偏差 0.3km/h: h1=1.0 は 0.3 で惰行の帯内、h1=0.5 は 0.6 で帯外）。ProblemReport_20260916 段3 で h1=0.5s が判定の 99% を決め惰行が消えた |
| ②を完全に外すと | 低速の定速保持など「①≈0 かつ惰行の減速が帯内」の場面で、ずれが直らず広がる（推測。コードの帰結で、実機未確認） |
| 現在の状況 | 20260921 6-11: 偏差 p95 0.46（目標 0.4）まで来ており、最大の未達はペダル往復 2.41 回/s（目標 0.4）。これは段3（調停）の仕事 |

## 検討した案

| 案 | 内容 | 判断 |
|---|---|---|
| 遅れをそのまま h1 にする | h1 = 実測の遅れ（0.3〜0.5s） | ②が 2〜3 倍強まり、ばたつきが増えるおそれ（20260916 段3 と同じ現象） |
| 下限つき | h1 = max(実測の遅れ, 下限値) | 下限値の決め方が別途必要 |
| **①と②を分ける（ユーザー暫定選択）** | 先読み（①）だけを実測の遅れにし、ずれへの反応（②）は段3 の調停に任せる | 暫定採用。ただし②を完全に外すと直らない場面があるため、「残す（÷1s のまま）か外すか」は未決。Claude 推奨は「今のまま残し、①だけ変える」 |
| ペダル別の先読み | アクセル約 0.5s・ブレーキ約 0.3s と別々にする。両方が「踏め」を出したら反応の速い方（ブレーキ）を優先する案（`reachability.decide_regime` と同じ考え方） | 未決 |
| **測定場所: 格子ステップ（ユーザー暫定選択）** | 手順2 の既存の格子ステップで測る。パターン変更なし | 暫定採用 |
| G 校正にステップを追加 | 格子の前に h1 を決め、格子の加速度軸も作り直す | 不採用（暫定）: 手順2 のパターン変更が要る。格子の軸を h1=1.0 のままにするなら不要 |

## ユーザー決定（2026-09-29）

- ProblemReport_20260921 では h1 の深掘りをここで止め、h1=1.0s のまま段3（ペダル調停）へ進む。
- 「A. どのペダルを踏むか決める」先読みが車によって違う点は、本レポートで別途扱う。
- 暫定方針: ①先読みと②ずれへの反応を分ける／遅れは格子ステップで測る。
