# 20261106 発進で速すぎなのにブレーキを戻し続けるのを、保つ・踏み増す・少しずつ離すで直す

**状態: 進行中（段19 決定・段20 実装中）**

発進のたびに +0.3〜+0.95 km/h の速すぎが出ます。車が先に出ていても、ブレーキは基準だけを見た計画どおりに浅くなり、最後に min へ一気に離れるのが原因です。対策は 2 つで、どちらも計画どおり段1〜7 で進めます。根拠は、本体の設定で走った W `drive_log_real_20261105_140418`・U `143701`・US06 `151245` です。
- 発進のブレーキの帯の中と帯の終わり: 保つ・踏み増す・少しずつ離す、の FB に置き換える
- 帯の無い発進: ブレーキを min へ離す時刻をアクセルが効く時刻に合わせる

## 問題

用語:
- **偏差** ＝ 実車速 − 基準（＋ が速すぎ）
- **t_go** ＝ 基準が停車から動き出す時刻
- **発進のブレーキの帯**（`launch_brake_band`、ログ `hold_scene = 3`。10-31 採用）＝ ゆっくり発進するとき、アクセルを使わずブレーキを離すだけで車を動かす区間。t_go − L（ブレーキの遅れ L 0.155 s）から、L 先の基準の加速度がクリープの加速度（両ペダル min のときの加速度。手順2 の値で 0.5 km/h のとき 2.2 km/h/s）を超える手前まで
- **保持の PI** ＝ 保持の場面（UDDS 1252 s の 1.6 km/h 一定）のために 10-30 に作った PI 制御。保持の場面・保持の手前の上り・発進のブレーキの帯で使っている
- **動き出す開度** ＝ min ＋ |meta `launch_breakaway_u_pct`| ＝ 8.905%

- 最新の 3 本の発進で、+0.3〜+0.95 の速すぎが出ています。最大は US06 5 s の +0.95 で、KPI の上限 1.0 の手前です
- 車が先に出ていても、ブレーキは計画どおり浅くなり続けます（例: W 137 s は偏差 +0.44 のまま 8.75 → 7.88 → min）

## 検討した案

| 案 | 内容 | 判断 |
|---|---|---|
| 開度を保つだけ | 速すぎの間は開度を保つ | 一部として使う。型 A は 8.8% で保っていても先に出たので、保つだけでは足りません |
| 速すぎを超えたら踏み増す | +0.3 を超えてから踏み増す | 不採用（ユーザー指摘）。遅すぎます。停止側と同じく、L 先の見込みで「超えそう」を見ます |
| 基準 < 0.3 km/h なら止まったものとして待つ（停止側の踏み増しの考え方） | 発進の這う基準で動き出す開度のまま待つ | 不採用。US06 5 s は基準 0.3 km/h 以上の帯が 2 s 以上続くので救えません |

| **帯の終わりも同じ規則（採用）** | 見込みが 0 以下になるまで min へ離さない | 採用（ユーザー決定） |
| **型 C は離す時刻を合わせる（採用）** | 計画の側で、min へ離す時刻をアクセルが効く時刻に合わせます | 採用（ユーザー決定）。走行中の「待つ」は、残ったら後で足します。急な発進で待つと、0.1 s ごとに約 −0.5 の遅すぎの恐れがあります（推測） |

## ユーザー決定（2026-11-06）

1. 発進のブレーキの帯の中だけ、保持の PI を使うのをやめ、L 先の偏差の見込み（今の偏差 ＋ 偏差の傾き × L）による次の規則に置き換える。保持の場面・上り（UDDS 1251〜1256 s）は保持の PI のまま

   | 見込み | ブレーキ |
   |---|---|
   | > +0.3（超えそう） | 1 回踏み増して待つ。量 ＝ 偏差の傾き ÷ 効き。上限 ＝ 動き出す開度 8.905%（まずこれで） |
   | 0 〜 +0.3 | 開度を保つ（浅くしない） |
   | ≤ 0（基準が追いつきそう） | FF へ向けて少しずつ離す（1 回離して待つ）。FF より浅くしない。いきなり離さない |
   | < −0.3（遅すぎ） | FF より浅く 1 回離して待つ（下限 min） |

2. 効きは 4.43 km/h/s/%（pkl meta `stop_release_gain_kmhs_pct`。停止側と同じ）
3. 型 B（帯の終わり）にも最初から同じ規則を使う。見込みが 0 以下になるまで min へ離さない
4. 型 C は「min へ離す時刻をアクセルが効く時刻に合わせる」だけをまず試す。先に出た分が残ったら、走行中の「待つ」を後で足す
5. 型 C も今回の対象にする（目的は発進の挙動を直すこと）

### 段19: 採否（議論）

**原因の確かめ直し（生ログ。Claude 2026-11-08）**
- ⑮⑯ はどちらも「型 A が測った開度までブレーキを深くした」ことが元。US06 48 は帯の最初に 8.67 → 8.95%、U 346 は帯の前に 9.06 → 9.10%（上乗せ 0.46% を帯へ持ち込み）。本体（深くしない）では同じ発進の偏差は ±0.1 以内
- 帯の中で ±0.3 の間に動かさないのは上乗せだけで、出す開度は FF ＋ 上乗せなので FF に沿って浅くなる（待ちの間も同じ）。困ったのは最初から残っていた上乗せ
- ⑰ W 11 は、車の上がり方が本体の約 2 倍（同じ日のぶれ）で、見込みが +0.3 を超えるまで FB が動かなかったのが主。上限の差 0.03% は小さい
- 型 B（帯の終わりの後、クリープだけの約 0.4 s）の内訳: ブレーキが min に着くまで 3 周期（全発進）・安全網 1 周期・アクセルが効くまで約 0.15〜0.2 s。計画のアクセル指令は 4 周期目か 5 周期目で、5 周期目は上り代の大きい発進（US06 500・567、U 1196、W 511）だけ → 1 周期の空き。2 周期以上ずらすとアクセルも遅れる（得 約 0.07 ／ 損 約 0.26 km/h／周期 ＝ B-2 が δ 0 を選ぶ理由）
- 計画の「戻る時間」（pkl: 遅れ 0.099 s ＋ 戻す量 ÷ 83 %/s ＋ 1 周期）では US06 500 でも 5 周期が要る計算（実機との差 約 5 ms で周期の境目）。計画の中からは空きが見えない

**決定（ユーザー 2026-11-08）**
- 型 A: 測った開度でブレーキを深くするのはやめる（帯の前の下限・帯の最初の持ち上げ）。測った開度は帯の中の踏み増しの上限としてだけ使う（pkl との深い方にはしない）
- 帯の中の動かし方は今のまま（±0.3・傾き ÷ 4.43・待ち 0.25 s。停止側と同じ形）。B-2 は on のまま
- わざとマイナスの偏差を作る案（旧 B-1）は採らない。B-1 は「ブレーキを min へ離す時刻を、アクセルまでの空きの分だけ遅くする（アクセルは遅らせない）」。空きは走行中に測る
- US06 500・567 に +0.5 前後が残ることは受け入れる。A と B-1 を入れて実機 3 モードで比べる
- 段22 の結果の分け方: 帯の終わりの偏差が ±0.15 以内で +0.5 超の発進がある → 500・567 以外ならその原因を報告／全部 +0.5 以下 → 型 B を閉じる／±0.15 を超えてばらつく → 先に帯の中の合わせ方を直す
