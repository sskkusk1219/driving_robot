# 要求内容

## 概要

タイムスケジュール機能（`.steering/20260705-timeschedule-table-ui` で実装完了済み）に対する3件の修正。
ループ再生機能の全体削除、P/N/D列の排他制御、ペダル開度プレビューの追加を行う。

## 背景

表エディタ実装後のユーザー確認で以下が判明:
1. 「ループ再生する」機能は不要（用途上、都度手動実行する運用のため）
2. P/N/D は物理的にシフトレバーの排他状態を表すため、同一行で複数ONは矛盾する
3. ボタン押下プレビューはあるが、ペダル開度（Acc/Brk）の推移が視覚的に確認できない

## 実装対象の機能

### 1. ループ再生機能の削除
- UI（チェックボックス・一覧の「ループ」列）を削除
- API（`loop` フィールド）・ドメインモデル（`TimeSchedule.loop`）・
  `ScheduleLoop` の巻き戻しロジック・DBカラムを削除
- 既存DBには `ALTER TABLE ... DROP COLUMN IF EXISTS loop` で追従

### 2. P/N/D の同一行排他制御
- チャンネル1(P)/2(N)/3(D) は同一行で同時に複数ONにできない
- ユーザーが最後にONにした列を優先し、同一行の他のP/N/D列は自動的にOFFにする
- スタート(ch0)・オプション列(ch4-15)は対象外（従来通り独立にON/OFF可）

### 3. アクセル・ブレーキ開度プレビューの追加
- 既存の「ボタン押下プレビュー」と同じBox内に、Acc/Brkの開度推移プレビューを追加
- 時刻軸に対する開度の変化が視覚的にわかること（区間ごとの線形補間を反映）

## 受け入れ条件

### ループ再生機能の削除
- [ ] 編集画面に「ループ再生する」チェックボックスが表示されない
- [ ] 一覧の「ループ」列が表示されない
- [ ] `TimeSchedule` / `ScheduleRepository` / `ScheduleLoop` / スキーマ / ルーターに `loop` への参照が残っていない
- [ ] DBの `time_schedules.loop` カラムが削除される（`scripts/setup_db.py` 実行で追従）
- [ ] `ScheduleLoop` はタイムライン終端に到達したら常に `on_complete` を呼ぶ（巻き戻しなし）

### P/N/D排他制御
- [ ] 同一行でP列をONにするとN/D列が自動でOFFになる（N/Dも同様に相互排他）
- [ ] スタート列・オプション列はP/N/D以外の列と独立に共存できる

### ペダル開度プレビュー
- [ ] 「ボタン押下プレビュー」と同じBox内にAcc/Brkの開度推移が表示される
- [ ] 開度の変化（線形補間区間）が視覚的に区別できる

## 成功指標

- pytest 全件パス（バックエンド変更を含む回帰確認）・ruff check パス
- Playwright MCP で3件の修正を実ブラウザ上で確認

## スコープ外

- シーケンス機能（Post-MVP、別タスク）
- P/N/D以外の相互排他ルールの追加
