# 20261031 踏み替えの直後に DOB が逆向きに残る（低速で作った推定の持ち越し）

**状態: クローズ（2026-10-31）**

ProblemReport_20261029 の問題のまとめ 3（UDDS 1264〜1266 s、16 km/h で速すぎ +0.64）。生データで追うと、DOB のブレーキの推定 −0.83 km/h/s は踏み替えの遅れから作られたものではなかった。8 秒前の低速の保持（1.6 km/h、発進側の表）で作られ、加速の間は更新されずに残り、16 km/h のブレーキにそのまま使われていた（`drive_log_real_20261029_073644.csv`）。保持の場面を入れた後（10/30）の UDDS でも同じ持ち越しが残っている。

結論: 案1（DOB の推定を 7.5 km/h 未満の「低速の箱」と本体の箱に分け、5〜10 km/h で混ぜる）を採用し、本体 yaml の `dob_split_low_speed` を true にした。実機 3 モード（`drive_log_real_20261031_195530`・`202654`・`205040`）で U 1264 s の偏差 +0.50 → +0.15、U 611 s +0.53 → +0.22、ブレーキの踏み始め 3 秒で |偏差|>0.5 になった回数 8 → 3。本体の箱どうしの持ち越し（US06 538 s）は残る（案3 は別レポートで扱う候補）。

## 問題

- 用語: DOB（外乱オブザーバ、C11）は「実際の加速度 − 表が予測した加速度」をペダル別にならして持つ（`tests/research/dob.py`。d_accel・d_brake）。ブレーキの d が負 ＝「表よりよく効いている」と読み、ブレーキを浅くする（上乗せは＋）
- 現象: UDDS 1263.75 s にアクセルからブレーキへ踏み替えた直後、DOB の上乗せが +2.35% → +0.7% → +0.45% と 2 秒以上ブレーキを浅くし続けた。偏差は +0.6 km/h（速すぎ）で 1.5 秒続いた
- 困ること: 速すぎなのにブレーキを浅くする（逆向き）。±0.5 の目標（UDDS 6.40 s）のうち 1264.8 s の 1.4 s がこれ。P（C10）はこの間 −0.2% 程度で打ち消せない
