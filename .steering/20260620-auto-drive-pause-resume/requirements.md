# 要求内容

## 概要

自動走行ページに「一時停止／走行再開」機能を追加する。一時停止すると、その瞬間の目標車速を保持したまま走り続け、ボタンは「走行再開」に切り替わる。再開で走行を続行する。

## 背景

自動走行ページには一時停止機能が全く実装されておらず、状態は `READY ⇄ RUNNING` の2値のみだった。走行中に一時的に走行プロファイルの進行を止めたい運用ニーズがある（フロントには `auto-drive.js` に未使用の `showPause` プロップだけが先行して残っていた）。

ユーザー要求（原文）:
1. 一時停止ボタンを押すと、その車速を保持する
2. 一時停止ボタンを押すと、ボタンが「走行再開」に変わる
3. 「走行再開」を押すと走行を再開する

挙動の確認（実機安全に関わるため確認）: **「その速度で走り続ける」**。
すなわち一時停止＝**基準速度タイムライン（経過時間の進行）を凍結**し、一時停止した瞬間の目標車速を PID で保持して走り続ける。ブレーキで停車させる挙動ではない。

追加のUI要望（実装中にユーザーから受領）:
- 走行開始すると、緑の「走行開始」ボタンが **白の「一時停止」＋赤の「走行終了」** に切り替わること（一時停止ボタンの色は白）。

## 実装対象の機能

### 1. 一時停止（pause）
- RUNNING 中に一時停止すると、基準速度タイムラインを凍結し、その瞬間の目標車速を PID で保持して走り続ける
- 状態が PAUSED になり、フロントのプレイヘッド（経過時間）が凍結する
- 一時停止中も安全チェック（過電流・逸脱・ウォッチドッグ）は継続

### 2. 走行再開（resume）
- PAUSED 中に再開すると、凍結したタイムラインの続きから走行を進める
- 状態が RUNNING に戻る

### 3. UI 切り替え
- 未開始: 「▶ 走行開始」（緑）
- RUNNING: 「⏸ 一時停止」（白）＋「■ 走行終了」（赤）
- PAUSED: 「▶ 走行再開」（緑）＋「■ 走行終了」（赤）
- 状態バッジに `● PAUSED`（アンバー）を表示

## 受け入れ条件

### 一時停止／再開
- [x] RUNNING で `/api/v1/drive/pause` を呼ぶと PAUSED に遷移し、経過時間が凍結する
- [x] PAUSED で `/api/v1/drive/resume` を呼ぶと RUNNING に戻り、タイムラインが続きから進む
- [x] 一時停止中も目標車速を保持してアクチュエータ制御が継続する
- [x] 一時停止中は KPI 集計・走行ログを記録しない（逸脱安全チェックは継続）
- [x] RUNNING/PAUSED 以外で pause/resume を呼ぶと 409 を返す

### UI
- [x] 走行開始後、ボタンが「一時停止（白）＋走行終了（赤）」に切り替わる
- [x] 一時停止後、ボタンが「走行再開（緑）＋走行終了（赤）」に切り替わる
- [x] 一時停止中も「走行終了」で終了できる

## 成功指標

- 既存テストを壊さず、pause/resume の単体・統合テストが追加され全テストが合格する

## スコープ外

以下はこのフェーズでは実装しません:

- 学習運転ページの一時停止（開ループの `LearningLoop` は対象外。`showPause` を渡さない）
- 手動運転の一時停止
