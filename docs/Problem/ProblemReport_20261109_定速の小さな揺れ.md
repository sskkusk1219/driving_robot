# 20261109 定速の小さな揺れ（偏差の ± の行き来）を P の帯と D で抑え、IWR で測る

**状態: 進行中（段0 完了・段1 は別レポート（ProblemReport_20261108_アクセルを効き始めで待つ）の完了待ち）**

定速・ゆるい坂で、偏差が ±0.05〜0.09 km/h を約 0.8 Hz で行き来し、アクセルも同じ周期で往復する。原因は C10 の P が
見込む効き（表の傾き）より実際の効きが 3〜4 倍強く、ループが設計の 3〜4 倍の速さで回って安定の限界の近くで揺れること。
小さい偏差だけ P を弱める（案1 の変形）と D（位相を進める）を順に試し、IWR（SAE J2951）を KPI に入れて判定する。
**実装は別レポートが終わってから始める（ユーザー指示 2026-11-09）。**

## 問題

- WLTP 1160〜1270 s・1690〜1720 s など定速で、アクセルを踏んだり緩めたりして偏差 0 を境に + と − を行き来する（ユーザー報告）。
- 偏差は小さく（p95 0.08〜0.09 km/h）、今の KPI（符号反転のしきい値 0.3 km/h）には数えられない。しかしペダルの往復は
  定速の区間で 1.3〜1.5 回/s と、往復 KPI（全体 ≤0.4 回/s）の 3 倍以上。運転の質の指標 IWR も大きくなり、US06 は法規の目安
  ±2 % を超えている。

## 議論で確認した事実

用語:
- **偏差** ＝ 実車速 − 基準（CSV の deviation_kmh。正 ＝ 速すぎ）。C10 の内部では 基準 − 実車速（遅れていれば正）
- **P の強さ** ＝ 偏差 1 km/h あたり何 % 足すか。C10 は「偏差を τ ＝ deviation_c（6）× 遅れ L で 0 に戻す加速度」を表の傾きで開度に直す
- **局所の効き** ＝ 開度を少し動かしたときに出る加速度 [km/h/s/%]
- **IWR**（Inertial Work Rating、SAE J2951）＝ 加速側の慣性仕事（加速度 > 0 の行の 加速度 × 進んだ距離 の合計）が基準より何 % 多いか。
  ＋はバタバタ運転、−はなまし運転。ここでは 10 Hz・フィルタなし・中心差分で計算

## 検討した案

| 案 | 内容 | 判断 |
|---|---|---|
| 案1 そのまま | 偏差 ±0.0X 以内で開度を固定 | 不採用。開度全体を固定するとゆるい坂の基準に追いつかない。P だけでも硬い不感帯は、帯を出た瞬間に強い P が蹴り帯の幅で往復する（以前の「調停の保持 → 矩形発振」と同じ） |
| **案1 の変形（採用）** | 小さい偏差だけ P をなめらかに弱める（帯の中は r 倍、外は今と同じ傾きで値が連続） | 採用。大きい偏差の取り返しはほぼ今と同じなので、local_gain_brake（10-28 不採用、P 全体が弱まり取り返しが遅れた）の負け方を避けられる |
| **案2（採用）** | IWR を KPI に入れる | 採用。現象をそのまま数字にでき、車に依存しない標準の指標。車速信号のノイズでも上がり、± が打ち消すので、往復の KPI と区間別の内訳を並べて見る |
| 案3a DOB を速くする | Tq を短くする | 不採用。同じ遅れを抱えた強い加速度の FB になり、かえって揺れやすい |
| **案3b D を足す（採用）** | P の偏差を 遅れ L 先へ延ばす（要る加速度 − 実測の加速度） | 採用。位相を進めて揺れを減衰させる。案1 の後に足して比べる |

## ユーザー決定（2026-11-09）

- IWR の目標は **WLTP と UDDS で −0.2〜+0.4 %**（法規 ±2 % より厳しい）。US06 は記録だけ
- 符号が 0 をまたぐこと自体は許容する。**IWR と往復回数が目標に入れば良い**
- 案1 の変形を先に実施し、その上に D を足す。比べ方は **off → 案1 → 案1＋D**
- 案1: **r ＝ 0.5・e ＝ 0.1 km/h**（実機で 0.2 と比べる）
- D: **Td ＝ 遅れ L（ペダル別）・実測の加速度の窓 0.3 s**
- 掛ける範囲は **7.5 km/h 以上の C10 の行**（低速は対象外）
- D は帯の中でも弱めず全部の強さで足す（Claude 提案、ユーザー了承）
- **実装は進行中の別レポートが終わってから始める**

## 各段の内容

### 段1: IWR を KPI に入れる

**内容**

- `tests/research/kpi.py`（または `mode_report.py`）に IWR を足す。基準・実車速を 10 Hz に線形補間し、中心差分の加速度で
  IWD ＝ Σ(加速度 > 0 の行の 加速度 × 車速 × Δt) を基準と実測で出し、IWR ＝ (IWD実測 − IWD基準) ÷ IWD基準 × 100 [%]
- 内訳: 基準の傾き |a| < 0.3 km/h/s（定速）・≧ 0.3（加速）・≦ −0.3（減速）ごとの寄与（全体の IWD基準 に対する %）
- レポートに目標（WLTP・UDDS −0.2〜+0.4 %）との判定を出す。US06 などは値と法規 ±2 % の参考表示だけ
- 既存ログ（213500・220744・223206）で、議論の値（+1.08・+1.41・+2.70 %）が出ることを確かめる

**調整値**

| 値 | 現在 | データの根拠 | 何に効くか | いつ決めるか |
|---|---|---|---|---|
| IWR 目標 | −0.2〜+0.4 % | ユーザー決定（2026-11-09） | 判定 | 決定済み |
| 定速の境 | 0.3 km/h/s | 仮の値（根拠なし。今回の分析で使った値） | 内訳の分け方だけ（判定には使わない） | 必要なら段6 で見直す |

### 段2: 案1 の変形（小さい偏差だけ P を弱める）

**内容**

- `fwd_plan.deviation_offset_detail` の P の加速度 `dev ÷ τ` を `f(dev) ÷ τ` に替える（I・DOB は今の dev のまま）:
  - |dev| ≤ e: f ＝ r × dev
  - |dev| ＞ e: f ＝ 符号 × (r × e ＋ (|dev| − e))（値が連続。外の傾きは今と同じ）
- 掛けるのは 7.5 km/h 以上の C10 の行だけ。保持の場面（hold PI）・惰行の補助（C12）・停車まぎわ（停C・stop_tail）・発進の帯には掛けない
- yaml `forward_map.c10_small_dev_band`（既定 false）・`c10_small_dev_e_kmh`・`c10_small_dev_r`。ログに f(dev) を出す列を足す
- `test_research_config` で既定値だけを固定する（本体 yaml の値は固定しない）

**調整値**

| 値 | 現在 | データの根拠 | 何に効くか | いつ決めるか |
|---|---|---|---|---|
| `c10_small_dev_r` | 0.5 | 半分データ由来: Ti ＝ 4τ（今の I）なら帯の中の PI の減衰 ζ ＝ r。ζ 0.5 から決める（車に依存しない）。r ＝ 0 は帯の中が I だけになり減衰のない揺れ（周期 約 13 秒）になるので不可 | 帯の中の揺れの減衰と速さ。「小さい偏差では c を 6 → 12」と同じ意味 | 段3 で問題があれば見直す |
| `c10_small_dev_e_kmh` | 0.1 | 仮の値: 符号反転のしきい値 0.3 の 1/3・KPI p95 0.4 の 1/4（試験車の揺れの大きさは根拠にしない） | 広いほど小さな揺れは消えるが、帯の中で FF のずれが流れる幅も広がる | 段3 の実機で 0.1 と 0.2 を比べる |

### 段4: D（加速度のずれで位相を進める）

**内容**

- P の加速度に D を足す: Δa_D ＝ Td ×（要る加速度 need − 実測の加速度 a_meas）÷ τ。案1 の帯は掛けない（帯の中でも全部の強さ）
- need は FF が使っている要る加速度（1.0 s の窓でなめらか）。基準の傾きは使わない（WLTP の 1 秒刻みの折れ点で毎秒段差が入るため）
- a_meas は直近 0.3 s の車速の直線の傾き（DOB の 1.0 s の窓とは別に持つ）
- 掛ける範囲は段2 と同じ。yaml `forward_map.c10_d_term`（既定 false）・`c10_d_window_s`。ログに Δa_D と a_meas を出す

**調整値**

| 値 | 現在 | データの根拠 | 何に効くか | いつ決めるか |
|---|---|---|---|---|
| Td | 遅れ L（pkl meta accel_lag_s / brake_lag_s） | データ由来（手順2 で車ごとに測る）。遅れの分だけ先を見る。D の強さは P の 1 ÷ deviation_c（今は 1/6） | 位相の進み（揺れの減衰） | 段5 で問題があれば見直す |
| `c10_d_window_s` | 0.3 | 仮の値: 遅れ 0.14 s・ノイズ 0.020 km/h/s（シミュレータ。開度への影響 約 0.02 %）。他の車では車速信号のノイズで決め直す必要あり | 短いほど進みが大きいがノイズが増える | 段5 の実機。他車ではノイズの実測で |
