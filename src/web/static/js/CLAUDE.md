# フロントエンド（`src/web/static/js/`）

- **自動運転ページの 3 段目（枠3・全体進捗の図）は「走行モード」の画面が正解**。シーケンス・スケジュールでも同じ描き方にする
  - 図は幅いっぱい・縦は図に描くモードの最高速から決める（`figMaxSpeed`）・図の横に文字やパネルを並べない
  - 画面上部の見出し行（「車: … 走行モード/シーケンス: …」・シーケンスの進み具合）は 3 画面とも出さない（ユーザー決定 2026-11-23）
  - シーケンスの走行中は、走っている段がモードならその基準車速を 1 軸目に出す（走行モードと同じ。2026-11-23）
  - シーケンスで図が縮む／形が変わる不具合を 3 回直している（2026-11-20）。枠3に何か足すときは、走行モード・シーケンス・スケジュールの 3 つで画面を撮って見比べてから終える
- 枠4（情報の行）の左の箱の「基準 / 偏差」の行は `showDevLine` で出す（走行モード・シーケンス・スケジュールで出す。学習運転は出さない）。基準の線は `showRefLine`。シーケンスのモードの段は基準・偏差の値、スケジュールの段・開始前は「基準 — / 偏差 —」（ユーザー決定 2026-11-26）
- WebSocket（`src/web/ws.py`）は値が変わらない間は送らない。グラフの線を受信した点だけで描くと途切れるので、点が来ない間は直前の値のまま描く（`auto-drive.js` の `trace`）
