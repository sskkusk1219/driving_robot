# 要求内容

## 概要

車両プロファイル一覧画面に、インライン名前編集機能とプロファイルコピー機能を追加する。

## 背景

現状、プロファイル名を変更するには編集フォームを開く必要がある。
名前だけ変えたいときの操作コストが高い。
また、似た設定のプロファイルを作りたいとき（例: PIDゲイン違いで比較検証）、
一から入力し直す手間がかかる。

## 実装対象の機能

### 1. 一覧ページでのインライン名前編集

- 一覧テーブルの名前セルに鉛筆アイコンを表示
- アイコンクリックでその行をインライン編集モードに切り替え
- テキスト入力欄でプロファイル名を編集
- Enter または入力欄のフォーカス離脱で保存（PUT /api/v1/profiles/{id} を呼ぶ）
- Escape で変更をキャンセル
- 保存成功時にトーストメッセージを表示

### 2. プロファイルコピー

- 一覧テーブルの操作列に「コピー」ボタンを追加
- クリックするとプロファイルのパラメータ（最大開度、最高車速、PIDゲイン、停止判定）を複製して新規プロファイルを作成
- 新しいプロファイルの名前は `{元の名前} のコピー`
- キャリブレーションデータはコピーしない（API が対応していないため）
- 作成成功時にトーストメッセージを表示して一覧を再読み込み

## 受け入れ条件

### インライン名前編集

- [ ] 一覧の名前セルに鉛筆アイコン（✎）が表示される
- [ ] アイコンクリックで名前セルがテキスト入力欄に切り替わる
- [ ] Enter / フォーカス離脱で API を呼び名前が更新される
- [ ] Escape で変更がキャンセルされ元の名前に戻る
- [ ] 空白名前での保存が弾かれる（バリデーション）
- [ ] 保存成功時に「名前を更新しました」トーストが表示される
- [ ] 保存中に他の行の編集が開始できないわけではない（複数行同時編集は禁止しない）

### プロファイルコピー

- [ ] 操作列に「コピー」ボタンが表示される
- [ ] クリックすると `{名前} のコピー` という名前の新規プロファイルが作成される
- [ ] パラメータ（開度・速度・PID・停止判定）がコピー元と同一になっている
- [ ] キャリブレーションデータは引き継がれない（空の状態）
- [ ] 作成後に一覧が再読み込みされる
- [ ] 成功時に「コピーを作成しました」トーストが表示される

## スコープ外

- キャリブレーションデータのコピー
- コピー先プロファイルへの自動遷移
- バックエンド側の新規 API 追加（既存の PUT / POST を活用）
