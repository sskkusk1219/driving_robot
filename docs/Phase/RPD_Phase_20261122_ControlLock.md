# RPD Phase 2026-11-22 WebUI の操作権（操作は 1 ウィンドウだけ）

**状態: クローズ（2026-11-22）** — 画面はユーザー目視で承認・main に反映

## 1. 背景
WebUI を 2 つ以上のウィンドウで開くと、どのウィンドウからでも操作できた。

| 起きること | 理由 |
|---|---|
| 後から選んだ車が、先に選んだ車を上書きする | 選んでいる車はサーバーに 1 つ（`vehicles/.active`） |
| 先のウィンドウは古い車名のまま「走行開始」でき、**画面と違う車の設定でアクチュエータが動く** | 車名は画面を開いたときに 1 回だけ読む。走行開始はサーバーの車を使う |
| 手動運転・キャリブで、2 画面からのジョグが 1 つのペダルに混ざる | 同じ車・同じ種類の対話ジョブは使い回す |

## 2. 決めた仕様（ユーザー決定 2026-11-22）
| 項目 | 決定 |
|---|---|
| 開いたとき | 「操作」「閲覧」を選ぶ画面。操作権が使用中なら「操作」は押せない（「使用中」） |
| 操作権 | 1 つだけ。閲覧はいくつでも |
| 閲覧でできること | どのページも見られる・スクロールできる。ログ・エラーの確認と CSV ダウンロードだけ可。それ以外は不可（停止・非常停止も不可） |
| 操作のウィンドウが閉じた | 操作権が空くだけ。閲覧は閲覧のまま |
| 空いた操作権の取り方 | 開き直す／読み直して「操作」を選ぶ |
| 操作のウィンドウを読み直した | 操作権を持ったまま戻る |
| 奪い取り | なし |
| 走行中に操作のウィンドウを閉じた | 走行は続く。止めるのは開き直して「操作」（約 10 s 後から）か GPIO 非常停止スイッチ |

## 3. 仕組み
```
ウィンドウ ──WS /ws/realtime?client_id&instance_id──▶ ControlLock（src/web/control.py）
   │  2 s ごとに "ping"                                  持ち主 = (client_id, instance_id, WS)
   │  接続直後に {"type":"control","role":...} を受け取る
   └─ GET 以外の /api/v1 に X-Client-Id / X-Instance-Id ──▶ ミドルウェア（src/web/app.py）
                                                          持ち主でなければ 403
```
| 部品 | 内容 |
|---|---|
| client_id | タブごと・読み直しで残る（sessionStorage `drv_client_id`） |
| instance_id | ページを読むたびに新しく作る（メモリのみ） |
| 読み直し | 持ち主の WS が切れてから `GRACE_S`=10 s 以内に同じ client_id が来たら付け替える |
| 通信の途絶 | ping が `STALE_AFTER_S`=10 s 来なければ切れた扱い → さらに 10 s 待って空ける |
| タブの複製 | 同じ client_id で持ち主の WS が生きている → `duplicate`。画面は client_id を作り直して選ぶ画面へ |
| 閲覧でも通す API | `/api/v1/control/*`、`POST /errors/client`（画面のエラーの自動報告）、`POST /errors/{id}/acknowledge`・`/unacknowledge`・`/acknowledge-all`。エラーの削除は不可 |
| 画面の制限 | 本文の押す・入力する操作を捕まえて止める（スクロールは通す）。ログ・エラーのページは外す（削除ボタンだけ不可）。キーのジョグも無視 |
| WS 配信 | `control_held`（誰かが持っているか）を追加 |

待ち時間 10 s と ping 2 s は**仮値**。Pi での読み直しが 1〜2 s で終わることから、その数倍の余裕を取った。車には依存しない。困ることがあれば `control.py` の定数で変える。

## 5. 残り・注意
- Claude の確認も操作権が要る。ユーザーが「操作」を持っている間、Claude は WebUI を操作できない。
- 閲覧のウィンドウでも、文字の選択など要求を送らない動作はできる。要求はサーバーが 403 で断る。
- 操作権の持ち主はサーバーのプロセスに 1 つ。uvicorn を `--workers` 2 以上で起動するとプロセスごとに持ち主ができ、2 つになり得る（今の起動方法は 1 プロセス）。
