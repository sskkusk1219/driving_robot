# 要求内容

## 機能名
フロントエンドページバリデーションポップアップ

## 要求詳細

### 1. キャリブレーションページ
- 車両プロファイルが選択されていない場合 → ポップアップ「車両プロファイルを選択してください」

### 2. 学習運転ページ
- 車両プロファイルが選択されていない場合 → ポップアップ
- キャリブレーションデータがない場合 → ポップアップ

### 3. 自動運転ページ
- 車両プロファイルが選択されていない場合 → ポップアップ
- キャリブレーションデータがない場合 → ポップアップ
- 走行モードが選択されていない場合 → ポップアップ

### 4. 自動運転ページ 3軸目修正
- reference_speed のデータが {time_s, speed_kmh} 形式なのに {duration_s, speed} でアクセスしている
- 走行モード選択時に車速パターン全体が3軸目に表示されるよう修正
