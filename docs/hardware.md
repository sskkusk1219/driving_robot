# システムのハードウェア構成
**driving_robot** - シャシダイナモ向け自動運転ロボットシステムのハードウェア構成をまとめます

## ハード構成
- ロボット制御装置
    - Raspberry Pi 5 16GB
- UPS 
    - 電源 30W(raspberry pi用)
    - 電源 100V→24V変換器(P-CON-CB用)
- IAI製アクチュエータコントローラ
    - P-CON-CB × 2台（アクセル・ブレーキ）
- IAI製アクチュエータ
    - アクセルペダル用 RCP6-RA6R-WA-42P-6-100-P3-M-MT
    - ブレーキペダル用 RCP6-RA7R-WA-56P-8-100-P3-M-ML

ケーブル類
    - アクチュエータとP-CON-CBを接続するケーブル 2本（IAI製）
    - USB-RS485変換ケーブル 2つ（P-CON-CBとPCを接続、1本につき1台を独立接続）
    - UPSとの通信確認用のUSB-RS232変換ケーブル 1つ
    - CAN読み取り装置: KvaserのUSB-CANインターフェース 1ch
        - シャシダイナモの実車速
    - LANケーブル
        - GUIアプリ操作用：IPを合わせて接続し操作する
- 非常停止スイッチ 2つ（GPIO並列接続、どちらを押しても同じ動作）
    - シャシダイナモ室内: 車両・アクチュエータ周辺の作業者用
    - 操作エリア: オペレータが操作しながら即停止できる用
- シグナルタワー

### アクチュエータ仕様（`docs/manuals/RCP6-ROD(MJ3751-2Q).pdf` より）

型式の読み方（1.1 型式構成）: `RCP6 - RA6R - WA - 42P - 6 - 100 - P3 - M - MT`
= シリーズ - タイプ - エンコーダー種類 - モーター種類 - **リード** - ストローク - コントローラー - ケーブル長 - オプション

| 項目 | アクセル RA6R | ブレーキ RA7R | 出典 |
|---|---|---|---|
| タイプ | ロッド・モーター上折返し(MT) | ロッド・モーター左折返し(ML) | 1.1 |
| モーター | 42□ | 56□ | 1.1 |
| エンコーダー | WA = バッテリーレスアブソ / 8192 pulse/rev | 同左 | 1.1 / 1.2.3 |
| **リード長** | **6 mm** | **8 mm** | 1.1 |
| ストローク | 100 mm | 100 mm | 1.1 |
| ボールねじ | 転造 Φ10mm C10 | 転造 Φ12mm C10 | 1.2.3 |
| 分解能（リード÷8192） | 0.00073 mm | 0.00098 mm | 1.2.3 |
| **最低速度**（リード÷0.8） | **7.5 mm/s** | **10.0 mm/s** | 1.2.1 注意書き |
| 最高速度（高出力設定**有効**） | 450 mm/s | 水平 420 / 垂直 350 mm/s | 1.2.1 |
| 最高速度（高出力設定**無効**） | 250 mm/s | 210 mm/s | 1.2.1 |
| 可搬質量 @100mm/s 水平（無効時） | 0.3G→40kg / 0.7G→20kg | 0.3G→50kg / 0.7G→30kg | 1.2.2 |
| 押付け力（電流制限 20/50/70%） | 53 / 132 / 185 N | 156 / 391 / 547 N | 1.2.6 |
| ロッド先端静的許容トルク | 1.5 N·m（変位角 ±1.0°） | 2.5 N·m（±0.8°） | 1.2.5 |
| 繰返し位置決め精度 / ロストモーション | ±0.01 mm / 0.1 mm 以下 | 同左 | 1.2.4 |

注意点:

- **最低速度以下の速度は設定してはいけない**（「設定した速度では動きません」1.2.1）。
  時間指定移動 `move_to_position_timed` はこの値でクランプする（`min_speed_for_lead`）。
- **高出力設定は PCON-CB パラメーター No.152**、出荷時は**有効**（1.1 注記10）。
  `config/settings.toml` の `max_speed_mm_s` は設定によらず安全なよう**無効時の値**を記録している。
- 現行の指令値 VCMD=100 mm/s・ACMD=0.3G は、最も保守的な組合せ（brake・高出力無効・垂直
  210mm/s）でも仕様内に収まる。走行中は全移動が三角プロファイル（加速度律速）で VCMD は
  binding しないため、上げる理由は現時点でない。
- 加減速度は「許容値以上の設定は行わないでください。振動発生、故障および寿命低下の原因」
  （1.2.2）。可搬質量表の残余から 0.7G までは余地があるが、現行の変更方向は微小移動で
  ACMD を**下げる**側（`acmd_for_move`）。
