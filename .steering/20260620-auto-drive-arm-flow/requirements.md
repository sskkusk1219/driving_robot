# 要求内容: 自動走行の開始挙動を学習運転と同じ arm フローにする

## 背景

自動走行ページの「▶ 走行開始」は現在、押すと即座に走行前チェック → RUNNING へ遷移していた。
学習運転ページは「arm（停車保持ブレーキ踏込 → 車速0確認 → 走行前チェック）→ 確認ポップアップ →
はい/いいえ」という二段階フローになっている。

## 今回の要求

自動走行ページの運転開始挙動を学習運転と同じにする。

運転開始ボタンを押すと:
1. プロファイルの停車中ブレーキ開度（`stop_brake_opening_pct`）まで踏み込む
2. 車速が 0 になっていることを確認する
3. 走行前チェックを実施する
4. 確認ポップアップを表示する（「はい」で走行開始、「いいえ」でキャンセル）

## 制約

- 共通で使えるコードは流用する（学習運転の arm/cancel ロジックを共通化して再利用）。
- 既存の `start_auto_drive` 直接呼び出し（READY からの開始）も後方互換で維持する。
