# 要求内容

## 概要

学習運転が ~30km/h 付近の狭い車速域しか走行できず、出来上がる逆モデル（特に減速側）の精度が
極端に低い。学習走行を全車速域（0〜0.9×max_speed）を掃くように再設計し、定常ブレーキ計測を
追加して、加速・減速とも R² ≥ 0.8 を達成する。

## 背景

実機ログ（2026/6/30 07:39）で学習した結果:

```
加速 MAE 4.943 / RMSE 8.017 / R² 0.587（18441点）
減速 MAE 7.780 / RMSE 10.258 / R² 0.096（20481点）  ← ほぼ無相関
```

根本原因は2つ（引き継ぎ: `~/.claude/plans/pid-pid-purrfect-knuth.md` 参照）:

- **A. 車速 ~30km/h 頭打ち**: `DRIVE_ACCEL` の離脱が早すぎる。`accel_hold_timeout_s=6.0` の強制
  打ち切り（`learning_loop.py:77,519`）＋ 包絡線ガバナが減速G上限を加速にも流用して加速が緩慢
  （`learning_loop.py:157,597`）＋ 低開度プラトーの早期離脱（`:511-520`）。COMBINED スイープも
  先頭20本が低開度（2–40%, `learning_drive.py:24,112`）で低プラトーに張り付く。これが「アクセル
  踏む→戻す→低速キープ」の反復として観測され、高速域がほぼ未採取になる。
- **B. 減速 R²≈0.096**: ブレーキレジーム（`dv_1.0<0`, `model_training.py:184-189`）が、長いコースト
  （brake=0・緩減速）と短いブレーキ踏み込み（brake>0・むだ時間遅れ）という異質な2集団を1本の
  線形 Ridge に混在。ラベルは大半 0＋過渡スパイクで、ブレーキの不感帯→急制動の非線形を
  `fit_intercept=False` の線形では表現できず R²≈0。加速側にある「固定開度で定常を採る」相当の
  ブレーキ定常計測が欠落している。

## 実装対象の機能

### 1. 減速 R² の原因調査（先行）
- 既存ログをオフライン分析し、減速側を coast(brake≈0) と brake>0 に分離して個別 R² を算出。
- brake_opening ↔ 実減速率の関係・むだ時間遅れを定量化し、データ起因かモデル起因かを切り分ける。
- 「定常ブレーキデータの追加だけで R²≥0.8 に届くか」を判断し、モデル改修の要否を確定する。

### 2. 全車速域までの加速スイープ（走行再設計）
- 加速区間が `accel_speed_cap`（0.9×max_speed）に到達するまで伸びるよう離脱条件を見直す。
- 加速開度スイープを「低開度多数」から「全域到達する数段」に再構成し、速度全域 × 異なる加速率を採取。
- 「踏む→戻す→低速キープ」の反復を解消する。

### 3. 定常ブレーキ計測フェーズ（新 PatternKind.BRAKE_HOLD）
- 高速域まで加速後、固定ブレーキ開度を一定保持して定常減速を記録（加速側プラトー保持と対称）。
- ブレーキ開度を数段スイープし、brake_opening↔減速率の清浄な定常サンプルを確保。

### 4. ブレーキモデル改修（条件付き・調査結果次第）
- 機能1が「データ追加だけでは不足」と示した場合のみ着手。着手前にユーザーへ方針確認。

## 受け入れ条件

### 全体
- [ ] 学習走行が概ね 0〜0.9×max_speed の全車速域をサンプルする（高速域の (v0, dv) が埋まる）
- [ ] 再 train 後の結果で **加速・減速とも R² ≥ 0.8**（in-sample, `_metrics`）
- [ ] 学習走行が **30分以内**に完走する
- [ ] プロファイルの **max_speed / max_decel_g を超えない**（ガバナ・スキップ型安全が機能）

### 減速 R² 調査
- [ ] coast/brake 分離の R² と brake↔減速率の関係を数値で示し、判断を design.md に記録

### 全車速域加速
- [ ] 生成パターンに「全域到達する加速段」が含まれ、加速が cap まで伸びる
- [ ] 「踏む→戻す→低速キープ」の低速反復が解消される

### 定常ブレーキ
- [ ] `PatternKind.BRAKE_HOLD` が追加され、固定ブレーキ保持→次段へ遷移する
- [ ] ブレーキ開度が数段スイープされ、`max_brake_opening` でクランプされる

## 成功指標

- 加速・減速 R² ≥ 0.8（定量）
- 学習走行 ≤ 30分（定量）
- 上限G・最高車速の逸脱ゼロ（定量）

## スコープ外

以下はこのフェーズでは実装しません:

- PID 自動適合フロー（前ステアリング `20260620-pid-auto-tuning` で完了済み）の変更
- ブレーキモデル改修（機能4）— 機能1の調査結果が必要と判断した場合のみ、ユーザー確認後に着手
