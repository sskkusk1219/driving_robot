# タスクリスト: 手動運転・キャリブレーション UI改善 + グラフ修正

## 要求
- 手動運転ページのUI改善（ボタン状態・ドラッグスライダー追加）
- キャリブレーションページを手動運転と同様のUIに統一
- 自動走行・学習運転ページのグラフ修正（Y軸最大値・ゼロ線・単位表示）

## タスク

### 手動運転ページ

- [x] 未走行時に「走行開始」ボタン、走行中に「運転終了」ボタンを表示（robotState で切り替え）
- [x] handleStart 関数追加（`/api/v1/drive/manual/start` 呼び出し）
- [x] PosRuler（三角形 + 0〜5000目盛り）を削除
- [x] DragSlider（左右ドラッグでアクチュエータ操作）を追加
- [x] DragSlider: 左ドラッグ=減少、右ドラッグ=増加、80ms スロットル
- [x] レイアウト整理: 上段パネル flex:1 で高さを埋める、下段は自然高さ

### DragSlider 共通コンポーネント化

- [x] `calib-components.js` に DragSlider を共有コンポーネントとして追加
- [x] zeroPos / fullPos オプション対応（キャリブレーション用 ZERO/FULL マーカー表示）
- [x] `manual.js` からローカル定義を削除し window.DragSlider を使用

### キャリブレーションページ

- [x] PosRuler を削除して DragSlider に置き換え
- [x] 手動運転と同じ構造: 上段パネル flex:1、下段は自然高さ
- [x] スライダー上に ZERO（緑線）/ FULL（赤線）マーカーを表示

### 自動走行・学習運転グラフ修正

- [x] G_PAD_B: 12 → 2 に変更し、y=0 グリッド線をチャート底辺に一致させる
- [x] maxSpeed を固定値 130 から動的計算に変更（モードプロファイルの最大速度を20の倍数に切り上げ）
- [x] 学習運転: 車両プロファイルの max_speed を DriveMonitorScreen に profileMaxSpeed として渡す
- [x] LearningScreen でプロファイル取得時に max_speed を保存して反映
- [x] 1軸目左上に "km/h" 単位ラベルを1箇所だけ表示（各目盛りへの付加なし）

## 実装後の振り返り

- 実装完了日: 2026-05-30
- DragSlider を calib-components.js に共通化したことで manual / calibration の両ページで再利用でき、コードの重複を回避できた
- キャリブレーション用 ZERO/FULL マーカーはスライダー上に視覚的に表示され、現在位置との関係が一目で分かるようになった
- G_PAD_B の変更（12→2）により y=0 ラインが底辺に揃い、グラフの可読性が向上した
- maxSpeed の動的計算により、モードや車両プロファイルに応じて適切なスケールが自動設定される
