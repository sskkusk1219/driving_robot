## 1. やること

| # | 問題 | 直し方 |
|---|---|---|
| 1 | セッションの状態が英語（completed・emergency） | 日本語（完了・非常停止・エラー・実行中・中断）。非常停止・エラーは赤 |
| 2 | 基準車速の無い走行（学習運転）でも灰色の「基準」の線が 0 km/h に引かれる | 基準が 1 点も無ければ線・凡例を出さない。途中だけ無い所は線を切る |
| 3 | グラフが幅 700px 止まり・横軸の時間の目盛りが無い・単位が無い | tests の走行ログの図（`tests/research/results/drive_log_real_*.png`）と同じ 2 段: 上＝車速 [km/h]（基準 灰の破線・実車速 オレンジ `#c8922a` 系）、下＝開度 [%]（アクセル 水色・ブレーキ 赤、0〜100 固定）。横軸は経過時間 [s]。横幅いっぱい。目盛りの文字は HTML（SVG を非等比に伸ばしても文字が伸びないように。`DriveMonitorScreen` と同じやり方） |
| 4 | 自動運転の行に走行モード名が出ない・「自動走行」がメニューの「自動運転」と違う | `GET /api/v1/modes/` で mode_id → 名前を引いて行に出す（見つからなければ出さない）。呼び名は メニューにそろえる（自動運転・学習運転・手動運転・PID 適合走行） |
| 5 | 学習サイクルは中のセッション（学習運転 1＋PID 適合走行 N）を 1 本ずつ開く | サイクルを開いたら、中の全セッションのログを時刻順につないだ 1 本の図・まとめを出す（横軸はサイクル開始からの経過秒。セッションの切れ目は縦の点線とセッション名）。中のセッションの一覧（個別の CSV・詳細）は図の下に残す |
| 6 | まとめが最高車速・平均逸脱・記録時間・サンプル数だけ | tests のレポートの KPI 表の形: 基準のある行で 最大逸脱（時刻つき）・偏差 p95 を出し、本番 `src/domain/control/kpi_monitor.py` の基準（最大 ≤1.0 km/h・p95 ≤0.4 km/h）で ✅/❌。基準が無い走行は「—（基準車速なし）」。最高車速・記録時間・サンプル数は残す。符号反転は今回は出さない（数え方が kpi_monitor の逐次集計に依存するため） |

## 2. 作り

- 画面だけ（`src/web/static/js/screens/logs.js`）。サーバーは変えない（`/api/v1/sessions/{id}/logs` を各セッション分取って画面でつなぐ）。
- 6000 行×数本の折れ線は、点が多いときは描く点を間引く（画面幅のピクセル数程度。最大・最小を残す間引き）。表は今のまま。
- p95 は |実車速 − 基準| の 95 パーセンタイル（基準が null の行は除く）。

## 4. 結果

段1（logs.js の 1〜6）実装済み。サーバー変更なし。

- 1: 状態を日本語化（非常停止・エラーは赤 #e06666、実行中は琥珀）
- 2: 基準が 1 点も無ければ線・凡例なし。途中の null・セッションの切れ目は線を切る
- 3: 2 段（車速／開度 0〜100 固定）・横幅いっぱい・目盛りと凡例は HTML・横軸は経過秒。1200 箱の最小・最大間引き
- 4: `/api/v1/modes/` でモード名を行に出す（見つからなければ出さない）。呼び名は 自動運転 などにそろえた
- 5: サイクルを開くと配下の全ログをつないだ図・まとめ（セッション境界に縦の点線＋名前）。配下の一覧は図の下に残した
- 6: 最大逸脱（t つき・≤1.0）・偏差 p95（≤0.4）に ✅/❌。基準なしは「—（基準車速なし）」。平均逸脱は p95 に置換

段2: 8081 のスタブで確認（スクリーンショット `.playwright-mcp/logs-after-cycle2.png`・`logs-after-learning.png`・`logs-after-emergency.png`）。コンソールエラーなし。合否は色つきの「合格／不合格」に変更（絵文字は Pi のブラウザで白黒の記号になるため）。モード名の表示はスタブにモードが無く未確認（コード上のみ）。
