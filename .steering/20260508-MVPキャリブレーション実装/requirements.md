# 要求定義

## 作業概要

MVPのキャリブレーション機能を実機で確認するためのハードウェアテストスクリプトを作成する。
少しずつアクチュエータをストロークさせてゼロフルを検出し、検出過程と結果をターミナルに出力する。

## 背景

- `CalibrationManager`（`src/domain/calibration.py`）はドメインロジックとして実装済み
- 実機での動作確認のためのハードウェアテストスクリプトが未作成
- 前回（20260507-過電流検知原点復帰実装）と同じパターンでスクリプトを作成する

## 機能要件

### 1. スクリプトの動作

1. Modbus 接続（両軸）
2. `enable_modbus_control → reset_alarm → servo_on → home_return`（両軸）
3. アクセル軸のゼロフルキャリブレーション実行
4. ブレーキ軸のゼロフルキャリブレーション実行
5. 結果表示

### 2. ターミナル出力（移動中・連続表示）

```
電流 a=  197.0mA b=   51.0mA  位置 a=    81 b=    87  (閾値:300mA)
```

- `a` = アクセル軸、`b` = ブレーキ軸（軸の役割に関わらず常にこの順序）
- 移動ステップごとに1行出力（連続）

### 3. ターミナル出力（ゼロフル検出後）

```
acc : xx mm = 0%, yy mm = 100%  brk : zz mm = 0%, qq mm = 100%
```

- `xx` = アクセルゼロ位置 [mm]
- `yy` = アクセルフル位置 [mm]
- `zz` = ブレーキゼロ位置 [mm]
- `qq` = ブレーキフル位置 [mm]
- 単位変換: `pulse × 0.01 = mm`（レジスタ単位: 0.01mm）

## 非機能要件

- `CalibrationManager`（ドメインクラス）は変更しない
- スクリプトは`ActuatorDriver`を直接使用する（独立した確認ツール）
- Ctrl+C で安全終了（home_return 後に Modbus 切断）
- スパイク判定アルゴリズムは`CalibrationManager._probe_contact()`と同一
