# 要求内容: GUI実装

## 概要

driving_robot の Web GUI を、Claude Design で作成したワイヤーフレームを基に実装する。

## 参照資料

- `docs/product-requirements.md` — プロダクト要求定義書
- `docs/functional-design.md` — 機能設計書
- `docs/architecture.md` — 技術仕様書
- Claude Design バンドル: `https://api.anthropic.com/v1/design/h/5rHxU8FSem5P2zYb_rJLlg`

## 対象画面

### P0（必須）
1. **初期化** — BOOTING/ERROR/STANDBY/INITIALIZING 状態の表示と初期化実行
2. **車両プロファイル** — 一覧・新規作成・編集
3. **キャリブレーション** — ジョグ操作（-10/-1/+1/+10）でゼロ/フル位置を設定
4. **走行モード** — 一覧・新規作成（CSV プレビュー付き）
5. **自動走行モニター** — 3 軸グラフ（基準 vs 実車速 / 開度 / 全体プロファイル）
6. **手動運転** — ジョグ操作でアクチュエータを直接制御
7. **学習運転** — 走行中のリアルタイムモニタリング
8. **ログ管理** — セッション一覧・詳細グラフ
9. **システム状態画面** — AC断・自動停止・走行前チェック NG

### Post-MVP（P1）
- タイムスケジュール一覧・編集
- シーケンス一覧・編集

## デザイン仕様

- デザイン: ワイヤーフレームの手書き風グレースケール (Patrick Hand フォント)
- レイアウト: 左固定サイドメニュー (180px) + 上部ステータスバー (52px)
- 解像度: 1920x1080 デスクトップ横長
- ナビゲーション: 初期化 / 車両プロファイル / キャリブレーション / 走行モード / 学習運転 / 自動運転 / 手動運転 / タイムスケジュール / シーケンス / ログ

## 技術要件

- React 18 + Babel（ブラウザ側トランスパイル）— ビルドなし
- WebSocket (`/ws/realtime`) でリアルタイムデータを受信
- REST API (`/api/v1/`) でデータ操作
- FastAPI の StaticFiles で配信
- 既存 `src/web/static/` を置き換え
