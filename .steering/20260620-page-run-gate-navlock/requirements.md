# 要求内容

## 概要

キャリブレーション・手動運転・学習運転・自動運転の4画面に「明示的な開始操作までアクチュエータを触らせない開始ゲート」と「実行中は他ページへ離脱させないナビゲーションロック」を追加する。

## 背景

キャリブレーション・手動運転画面はページを開いた瞬間からアクチュエータ（ジョグ／スライダ等）を操作できてしまい、誤操作のリスクがあった。また4画面とも実行中でも自由に他ページへ遷移でき、操作途中での誤遷移や保持ブレーキの取り残しにつながる恐れがあった。安全性向上のため、開始操作を必須化し、実行中のページ離脱を制限する。

## 実装対象の機能

### 1. キャリブレーション画面の開始ゲート
- 初期画面では「キャリブレーション保存」ボタンの位置を「▶ 開始」ボタンとする
- 開始ボタンが押されるまでアクチュエータ操作は不可。実行可能になるまで開始ボタン以外はグレースケール表示
- 開始ボタン押下で「開始しますか？」ポップアップ（はい／いいえ）を表示
- 「はい」でアクチュエータ操作可能になり、ボタンは「キャリブレーション保存」へ変化

### 2. 手動運転画面の開始ゲート
- キャリブレーション画面と同じ挙動にする
- 「実行中」は `robotState === 'MANUAL'` を真実とする

### 3. 4画面共通のナビゲーションロック
- キャリブレーション・学習運転・自動運転・手動運転の実行中は、他のページに移動できない制約を追加

## 受け入れ条件

### キャリブレーション画面の開始ゲート
- [x] 初期状態で保存ボタンが「▶ 開始」として表示される
- [x] 初期状態でジョグ／スライダ／ZERO・FULL／原点ボタンがグレーで操作不可
- [x] 開始押下で「開始しますか？」ポップアップが表示される
- [x] 「はい」でアクチュエータ操作が有効化され、ボタンが「キャリブレーション保存」に変化する

### 手動運転画面の開始ゲート
- [x] 初期状態でアクチュエータ操作系がグレーで操作不可、「走行開始」のみ活性
- [x] 走行開始押下で「開始しますか？」ポップアップが表示される
- [x] 「はい」で手動運転開始APIを呼ぶ

### ナビゲーションロック
- [x] 実行中はサイドバーの非アクティブ項目がグレー表示になる
- [x] 実行中に他ページを押しても遷移せず、トーストで通知される
- [x] 実行終了（保存／停止）でロックが解除される

## 成功指標

- 開始操作なしにアクチュエータを操作できないこと（誤操作防止）
- 実行中に意図せず他ページへ遷移できないこと

## スコープ外

以下はこのフェーズでは実装しません:

- バックエンドAPI（開始/停止/jog等）の新規追加・変更
- キャリブレーション開始に対応するバックエンドの開始エンドポイント（開始ゲートはクライアント側のみで実現）
- 学習運転・自動運転の開始確認フロー（既存の arm→確認→開始 を流用）
