# 20261109 定速の小さな揺れ（偏差の ± の行き来）を P の帯と D で抑え、IWR で測る

**状態: 進行中（PDCA-4b 本体で再現の確認中。PDCA-4〔ぼかし σ 0.15・ずれ上限 0.1・減速中はぼかさない ＋ FF の速い成分を r で割る〕を採用: IWR W +0.28・U −0.04 %、偏差は off と同等 `072303`・`075545`・`071030`）**

定速・ゆるい坂で、偏差が ±0.05〜0.09 km/h を約 0.8 Hz で行き来し、アクセルも同じ周期で往復する。原因は C10 の P が
見込む効き（表の傾き）より実際の効きが 3〜4 倍強く、ループが設計の 3〜4 倍の速さで回って安定の限界の近くで揺れること。
小さい偏差だけ P を弱める（案1 の変形）と D（位相を進める）を順に試し、IWR（SAE J2951）を KPI に入れて判定する。
**実装は別レポートが終わってから始める（ユーザー指示 2026-11-09）。**

## 問題

- WLTP 1160〜1270 s・1690〜1720 s など定速で、アクセルを踏んだり緩めたりして偏差 0 を境に + と − を行き来する（ユーザー報告）。
- 偏差は小さく（p95 0.08〜0.09 km/h）、今の KPI（符号反転のしきい値 0.3 km/h）には数えられない。しかしペダルの往復は
  定速の区間で 1.3〜1.5 回/s と、往復 KPI（全体 ≤0.4 回/s）の 3 倍以上。運転の質の指標 IWR も大きくなり、US06 は法規の目安
  ±2 % を超えている。

## 議論で確認した事実

用語:
- **偏差** ＝ 実車速 − 基準（CSV の deviation_kmh。正 ＝ 速すぎ）。C10 の内部では 基準 − 実車速（遅れていれば正）
- **P の強さ** ＝ 偏差 1 km/h あたり何 % 足すか。C10 は「偏差を τ ＝ deviation_c（6）× 遅れ L で 0 に戻す加速度」を表の傾きで開度に直す
- **局所の効き** ＝ 開度を少し動かしたときに出る加速度 [km/h/s/%]
- **IWR**（Inertial Work Rating、SAE J2951）＝ 加速側の慣性仕事（加速度 > 0 の行の 加速度 × 進んだ距離 の合計）が基準より何 % 多いか。
  ＋はバタバタ運転、−はなまし運転。ここでは 10 Hz・フィルタなし・中心差分で計算

## ユーザー決定（2026-11-09）

- IWR の目標は **WLTP と UDDS で −0.2〜+0.4 %**（法規 ±2 % より厳しい）。US06 は記録だけ
- 符号が 0 をまたぐこと自体は許容する。**IWR と往復回数が目標に入れば良い**
- 案1 の変形を先に実施し、その上に D を足す。比べ方は **off → 案1 → 案1＋D**

- D は帯の中でも弱めず全部の強さで足す（Claude 提案、ユーザー了承）

## 各段の内容

### 段1: IWR を KPI に入れる

**内容**
