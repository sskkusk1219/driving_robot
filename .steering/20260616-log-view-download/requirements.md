# 要求: ログの確認・ダウンロード機能

## 背景

ログ画面（`/static/index.html` → 「ログ」）は走行セッション一覧を表示し、
行をクリックすると速度ログの折れ線グラフのみ表示する。しかし

- **中身を確認できない**: 速度グラフ以外のログ内容（アクセル/ブレーキ開度・
  電流・位置・タイムスタンプ）を画面で確認できず、実際のデータを精査できない。
- **ダウンロードできない**: ログを CSV 等で取り出す手段が一切ない。
  バックエンドにも `/logs.csv` のようなダウンロード API が存在しない。

参照: `docs/result/2026-06-16 062836.png`

## 要求内容

1. セッションのログ内容を画面上で確認できること。
   - 速度グラフに加え、サマリ（最高車速・平均逸脱・記録時間・サンプル数）と
     明細テーブル（時刻・基準/実車速・開度・電流）を表示する。
2. セッションのログを CSV ファイルとしてダウンロードできること。
   - アーカイブ（`ArchiveManager._export_to_csv`）と同じ列構成を踏襲する。

## 非機能・制約

- 既存のミニマルな UI スタイル（`Box` / `Btn` / `window` カラー）に合わせる。
- 読み取り専用。`SessionRepository` の既存メソッドを再利用する。
- API は既存の `/api/v1/sessions/` ルータに追加し、設計書のエンドポイント節も更新する。
